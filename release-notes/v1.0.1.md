# v1.0.1

ClaudeWorks now defaults to Claude Opus 4.8, with safer handling of an existing `claude` shell alias and a fix for plugins that ship commands or agents as directories.

## Highlights

- **Opus 4.8 is the new default.** New profiles and any profile set to "Opus" now launch on Claude Opus 4.8. Existing Opus profiles pick it up automatically — no re-configuration needed.
- **Safer `claude` alias handling.** If you already have a shell alias named `claude`, ClaudeWorks now asks before taking it over, and migrates older aliases to the current launch format on startup.
- **New docs site and landing page** at the project website, with search-friendly metadata.

## Fixes

- **Plugins that ship commands or agents as directories now show all their items.** The scanner (and the curated marketplace / list-addons views) previously expanded only some directory-style entries, so multi-item plugins could under-report what they provide.

## Known issues

- None.

## Install

Download `ClaudeWorks-1.0.1-arm64.dmg` from this release and drag it to `/Applications/`. On first launch, macOS Gatekeeper will warn — approve via **System Settings → Privacy & Security → Open Anyway**.
